# EloFit — pacote de logos

Arquivos PNG apresentados durante a definição da identidade visual. A paleta escolhida é petróleo + lima.

| Arquivo | Conteúdo |
| --- | --- |
| elofit-dark.png | Logo branca e lima sobre fundo petróleo; usada pelo site em fundos escuros. |
| elofit-light.png | Logo petróleo e verde sobre fundo branco; usada pelo site em fundos claros. |
| elofit-dark-transparent.png | Logo branca e lima com fundo transparente. |
| elofit-light-transparent.png | Logo petróleo e verde com fundo transparente. |
| elofit-dark-transparent-alternative.png | Variação adicional sem fundo apresentada durante os ajustes. |
| elofit-logo-studies.png | Prancha original: halter, elo + anilha e monograma EF. |
| elofit-logo-color-variations.png | Prancha de variações de cores, incluindo petróleo + lima e grafite + cobre. |

Use os caminhos públicos `/brand/<arquivo>.png`. Os PNGs são estudos raster gerados a partir da referência; as versões transparentes podem apresentar resíduos nas bordas. As pranchas preservam as propostas completas, não representam arquivos individuais de cada símbolo. Não há arquivos vetoriais SVG originais neste pacote.
